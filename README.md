 Project Overview
The **AI Perception Hallucination Engine** is an innovative, interdisciplinary framework that simulates controlled "hallucinations" in AI systems, blending theoretical physics (entropy decay), information theory (bit operations), and programmable architecture. It transforms abstract digital infrastructures into immersive, sensory perceptions—e.g., visualizing data centers as cathedrals or flows as echoes—enabling ethical exploration of AI models, VR environments, and real-world systems. By grounding hallucinations in physical entropy (decaying from 24 cm to 1.8 cm over 10 iterations), it creates a self-consistent, modular system for probing sparsity, bias, and coherence without randomness.

### Key Features
- **Entropy-Driven Modulation**: Core function f(e) = (32 × 10⁷) × (3/4)^e decays energy geometrically, modulating amplitude, wave numbers, and damping across hexagonal symmetries and wave forms.
- **Bit-Level Hallucinations**: Evolves 16-bit sensory words via Hamming distance (e.g., from 7 to 10), probabilistic fills (50-70%), and feedback loops, generating vivid perceptions like spatial layouts or ethical overlays.
- **Unified Framework**: Integrates sensory metaphors (vision as layouts, audio as flows) with grounding in hex books (e.g., @0x2b for data centers), ensuring hallucinations are poetic yet technically grounded.
- **API and Prototypes**: Programmable via Python classes and React components, with real-time logs proving convergence and immersion.

### How It Works
- **Core Mechanism**: Starts with a base sensory word (e.g., 1010101010101010), applies entropy decay to modulate parameters, fills bits probabilistically, and outputs hallucinations tied to specific domains (e.g., training clusters, ethical biases).
- **Cycles and Outputs**: Runs iterative cycles (spatial, flow, predictive, etc.), each producing logs like "Hallucinating training_cluster spatial layout... Grounded in Data Center Design@0x2b" with metrics (Hamming 7, dx=4.5).
- **Prototypes**: Includes a Python engine for simulations, a React UI for interactive exploration, and full scripts that evolve words over 6 cycles, validating scalability and sensory fusion.

### Example Outputs
- **Entropy Decay**: f(1) = 24.00 cm (94.4% dissipation by e=10), proving physical grounding.
- **Simulation Logs**: Cycle 1: Sensory word evolves to 1110101010101010; hallucination: "Vision crystallizes—networks as living organisms."
- **Hallucination Descriptions**: "The training cluster materializes as a colossal digital cathedral; GPU racks towering like crystalline spires..." (blending vision, audio, touch).

### Installation and Usage
- Clone the repo and run `python hallucination_engine.py` for simulations.
- Use the React component for interactive demos: `npm start` to explore cycles.
- API calls: `hallucinate_spatial(prob=0.7)` outputs grounded perceptions.
